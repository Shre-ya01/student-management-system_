# Student Management System

A modern and responsive Student Management System website built using HTML, CSS, and JavaScript. This project helps manage student records through a simple and user-friendly dashboard.

## Features

- Dashboard displaying student statistics
- Add new student records
- View all registered students
- Search students by name, roll number, or email
- Edit student details
- Delete student records
- Filter students by department
- Form validation
- Prevent duplicate roll numbers
- Responsive design for desktop and mobile devices
- Save student records using browser LocalStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run the Project

1. Download or clone this repository.
2. Keep all three source files in the same folder.
3. Open `index.html` in your web browser.
4. Use the dashboard to add, search, edit, and delete student records.

## Data Storage

Student records are stored in the browser's LocalStorage. The data remains available in the same browser on the same device unless the browser storage is cleared.

**Note:** This version uses frontend technologies only. It does not currently use a Java backend or a separate database.

## Future Enhancements
