Student Management System (SMS)

Version 1.0 • Client-side Web App

The Student Management System is a modern, responsive web application designed to help educational institutions and administrators track student information with ease. Built entirely with semantic HTML5, responsive CSS3, and modern Vanilla JavaScript.

Key Highlights & Features

Persistent LocalStorage

All student records remain saved in your web browser even after refreshing or closing the tab.

Strict Validation

Prevents duplicate roll numbers and validates email and phone number formats before saving.

Live Search & Filtering

Instant real-time search across student names, roll numbers, and department filter dropdowns.

Full CRUD Support

Create new student records, Read/View student data, Update existing entries, and Delete unwanted records.

Responsive Design

Optimized for laptops, desktops, tablets, and smartphones with mobile drawer navigation.

Zero Dependencies

Pure frontend implementation without heavy external frameworks or complex backend setups.

Built With:

HTML5 CSS3 Vanilla JavaScript (ES6+) Browser Web Storage API
